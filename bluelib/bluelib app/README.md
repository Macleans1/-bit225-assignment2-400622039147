# BlueLib Catalogue (BIT225 Assignment 2)

A single-page library catalogue built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Books stored in a JS array and rendered dynamically as cards
- Live search by title and category filter
- Add Book form with validation (all fields required, copies a whole number >= 0)
- Borrow button reduces copies; shows "Out of stock" and disables at 0
- Responsive grid: 3 columns desktop, 2 tablet, 1 mobile (< 600px)

## Structure
index.html, css/style.css, js/app.js
